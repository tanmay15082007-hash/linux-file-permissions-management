# Linux File Permissions Management

## Project Overview
This project is part of the Google/Coursera Linux and SQL course. It focuses on understanding and managing file permissions in a Linux environment using command-line commands.

The project demonstrates how to inspect file and directory permissions, understand permission structures, and modify access permissions to improve basic system security.

## Objectives
- Inspect file and directory permissions using Linux commands.
- Identify hidden files and directories.
- Understand read, write, and execute permissions.
- Modify permissions for users, groups, and others.
- Apply access restrictions to files and directories.

## Tools & Technologies
- Linux Command Line
- `ls -la`
- `chmod`
- Linux File System

## Tasks Performed

### 1. Check File and Directory Details
Used the `ls -la` command to display detailed information about files, directories, and hidden files, including their permissions.

### 2. Understand Permission Strings
Analyzed Linux permission structures to understand file types and access permissions for:
- User
- Group
- Others

### 3. Modify File Permissions
Used the `chmod` command to remove unauthorized write permissions from files.

### 4. Modify Hidden File Permissions
Updated permissions of a hidden file (`.project_x.txt`) by removing write permissions from the user and group and adding read permission for the group.

### 5. Modify Directory Permissions
Removed group execute permission from the `drafts` directory using the `chmod` command.
